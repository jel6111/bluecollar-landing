# 블루칼라 미션 8 · 지표 설계서

작성자 정이레 · 2026-11-17

## 측정 목적

현장 사진과 설명을 작업기록으로 남길 수 있는 별도 과제 데모에서, 신규 방문자가 가입을 거쳐 첫 기록을 저장하는 흐름을 관찰한다. 핵심 지표는 가입 이메일 확인 후 24시간 이내 첫 기록 저장률이다.

퍼널: 랜딩 방문 → 가입 화면 → 가입 요청 → 이메일 확인 → 기록 목록 → 등록 화면 → 저장 성공

| 지표 | 계산식과 기준 | 결과를 보고 판단할 항목 |
|---|---|---|
| 채널별 방문 세션 | GA4에서 UTM source/medium/campaign별로 미션 8 랜딩에 진입한 세션 수 | 유입이 적은 채널은 문안과 노출 위치를 점검한다. |
| 가입 시작률 | Amplitude에서 방문 세션 중 같은 세션에 signup_started를 보낸 세션 수 ÷ landing_viewed 세션 수 | CTA 클릭 이후 가입 화면 진입에 마찰이 있는지 점검한다. |
| 이메일 확인 완료율 | signup_submitted를 보낸 브라우저 중 48시간 이내 같은 device ID에서 signup_confirmed가 생긴 브라우저 수 ÷ signup_submitted 브라우저 수 | 가입 안내, 메일 수신, 확인 링크 복귀를 점검한다. |
| **24시간 내 첫 기록 저장률** | signup_confirmed 고유 신규 계정 중 확인 시각 이후 24시간 이내 record_created가 처음 관측된 계정 수 ÷ signup_confirmed 고유 신규 계정 수 | 가입 후 내 기록 진입과 저장 폼 중 어디에서 개선이 필요한지 확인한다. |
| 등록 화면 저장률 | record_create_started 이후 같은 세션의 성공 record_created가 있는 세션 수 ÷ record_create_started 세션 수 | 입력 항목과 사진 업로드 안내를 점검한다. |

## 집계 기준

- KST로 주간 집계한다. 24/48시간 전환율은 관찰 창이 닫힌 코호트만 분모에 포함한다.
- 테스트 링크는 utm_source=qa로 표시한다. Amplitude에서 traffic_type=qa를 제외하며, GA4는 별도 데이터 구분이나 QA UTM 제외를 사용한다.
- 첫 기록은 미션 8에서 성공한 첫 관측 이벤트로 정의한다. 저장 결과를 검증하지 않은 클릭은 세지 않는다. 브라우저가 달라지거나 수집을 거부하면 가입 연결이 관측되지 않을 수 있다.
- Amplitude의 30분 기준 세션과 GA4의 세션은 각 분석 도구에서 따로 집계한다. 전체 서비스 이용자 수나 검증된 사업 성과로 해석하지 않는다.
- 미션 11에서는 채널별 방문·전환수와 전환율을 나란히 보고, 건수가 적은 채널은 관측 기간이나 모집 범위를 늘린다.
