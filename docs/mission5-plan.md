# 미션 5 기획과 미션 4 반영

## 사용자와 목표

- 1차 대상: 작업 사진을 카카오톡으로 공유하는 40~60대 기공.
- 문제: 현장 사진 재검색, 현장별 구분, 반복 설명, 보고 자료와 경력 자료의 분산.
- 해결: 평소처럼 사진을 카카오톡으로 보내면 현장·날짜별 작업기록과 보고 링크가 만들어지고 보관함·포트폴리오에 누적된다.
- 기대효과: 오늘의 보고를 간편하게 하고, 같은 기록을 나중에 다시 찾고 대표 작업으로 공유한다. 효과는 아직 실제 사용자 행동으로 검증해야 한다.
- 핵심 행동: 랜딩 CTA → 카카오톡 채널 진입 → 첫 사진 전송. 랜딩의 보조 행동은 사용 방법 섹션으로 이동한다.

## 페이지 순서

1. 히어로: 한 문장 가치, 카카오톡 CTA, 사용 방법 이동.
2. 문제: 사진 찾기·현장 구분·설명 반복·기록 소실.
3. 해결: 사진 전송 → 기록 정리 → 결과 활용.
4. 제품 예시: 작업기록과 보고, 로그인 없는 수신자 화면, 누적 포트폴리오.
5. 베타 단계 안내: 제품 구현과 사용자 검증 상태 구분.
6. 대상 사용자와 최종 CTA.

## Figma MCP에서 확인한 결정

- 미션 4 스타일가이드 `85:340`: Noto Sans KR, Primary `#2563EB`, Text `#0F172A`, Neutral `#F8FAFC`, 큰 버튼.
- Hi-Fi `85:423`: 작업기록 정리, 보고 미리보기, 수신자의 로그인 없는 외부 열람. 현장 작업 사진을 재사용.
- 랜딩은 앱 화면의 픽셀 복제가 아니라 제품 흐름을 설명하는 반응형 페이지다. 미션 4의 색과 주요 행동, 시연 사진을 연결했다.
- 실제 서비스 `jel6111/parancollar`의 카카오톡 채널 주소와 공개 제품 URL을 확인해 CTA와 푸터에 사용한다.

## 검증

기능 구현은 완료되어도 현장 반복 사용은 아직 확인되지 않았다. 미션 3 계획대로 8~10명 모집, 6명 첫 전송, 4명 실제 보고 링크 활용, 3명 2주 내 재사용을 목표로 관찰한다. 이 숫자는 **계획**이며 성과가 아니다.
