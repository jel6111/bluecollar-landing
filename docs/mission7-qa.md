## 1묶음 검사

- 새 브랜치/제출 저장소 origin과 시작 커밋.
- 새 이름·미연결 ref/null·confirmed=false, 빈 환경 예시.
- 실제 환경/연결 파일 부재, 새 포트/폴더, 로컬 Supabase 새 이름/포트.
- 미션 6/7 자동 Git 배포 차단과 미션 6 문서·기존 SQL 원본 보존.
- 실행/DB/브라우저 명령의 선행 가드와 가드 종료 동작.
- 새 문서 상대 링크와 키/토큰 형식 누락 여부.

이 검사는 클라우드·네트워크·Docker·회원가입을 실행하지 않는다. 기능 검증용 lint/build/브라우저/DB 통과로 해석하지 않는다. build를 포함한 실행 명령은 의도적으로 차단되어 있다.
