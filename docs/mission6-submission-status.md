1. 기능·화면·입력·오류·DB/Storage 명세와 운영/미션 5 자원 분리.

3. 서버 검증, 중복 제출/오래된 요청 방지, 로딩·에러·빈 상태·없는 주소.
4. 비공개 Storage의 사진 1장 업로드·조회·유지·교체·제거와 실패 보상/정리 큐.

6. 과제 전용 Vercel의 Production 환경 변수·서버 키 Secret·수동 공개 배포.
7. lint/build, 단위 13개, 클라우드 DB/Storage 7개, 공개 배포 브라우저 11개 통과.
8. 공개 HTML 2개·스크립트 12개에 비밀 키 없음, 배포 오류 로그 0건. 테스트 후 가상 예시 2건·사진 1장·정리 큐 0건·연결 없는 파일 0건.
9. README·QA·실행법·환경 변수 이름·배포 URL 갱신.

## 확인 범위와 남은 선택 사항

- 사진 URL 오류/재조회는 403 응답을 주입해 검증했다. 실제 10분 대기 후 URL 만료는 별도 미확인이다.
- 런타임 의존성 감사는 0건. 배포 설치 로그의 개발 도구 포함 감사는 10건(9 high, 1 moderate)이며 강제 버전 변경은 적용하지 않았다.
- 인증·사용자별 접근 권한은 미션 7 범위다. 현재는 가상 자료만 넣는 공용 과제이며 모든 방문자가 기록을 조회·수정·삭제할 수 있다.
- PR 제출/멘토 리뷰 요청은 사용자가 정하는 제출 절차에 맞춰 진행한다. main 병합과 기존 서비스·미션 5 설정 변경은 하지 않는다.
