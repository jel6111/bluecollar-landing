# 미션 8 로깅 QA

## 확인 완료

- 미션 8 웹 앱은 전용 Vercel에서 HTTP 200을 반환한다. 모바일 너비 390px에서 핵심 버튼과 가로 넘침을 확인했다.
- 분석 동의 전과 철회 후에 이벤트를 버린다. 타 사이트 Origin, 서버 전용 성공 이벤트의 클라이언트 호출, 비로그인 기록 조회 이벤트를 차단한다.
- 허용한 UTM 조합을 유지하고 이메일·인증 쿼리 값을 제거한다. QA 캠페인을 별도 표시한다.
- 단위 검사 6개에서 채널 링크, 허용 목록, 가명화·중복 방지, QA 분리를 확인했다. 인증 단위 검사 6개, lint, build, 분리 검사도 통과했다.
- 상세 실측 응답은 로깅 증빙 ZIP의 qa/앱_응답_실측.csv에 담는다.

## 확인 대기

| 대상 | 현재 상태 | 증빙 |
|---|---|---|
| Amplitude | 연결된 조직의 default 프로젝트만 조회됨. 미션 8 수집 대상과 키를 확인하기 전 앱 전송 비활성 | 전용 프로젝트에서 QA 이벤트 수집 화면 또는 실제 CSV |
| GTM | 미션 8 전용 컨테이너 ID와 태그 게시 대기 | Google 태그·GA4 이벤트 태그와 Preview 화면 |
| GA4 | 미션 8 속성·웹 스트림 측정 ID 및 DebugView 수신 대기 | DebugView 화면 또는 실제 CSV |
| 회원 이벤트 | 미션 8 전용 Supabase와 외부 가입 메일 준비 대기 | 공개 앱에서 신규 가입 → 확인 → 기록 저장을 1회 수행 |
| 홍보 | 카카오톡·네이버 블로그·인스타그램 UTM 및 문안 준비 | 대상 채널의 실제 게시 URL 또는 캡처 |

QA 예시·앱 응답은 벤더 수집 자료로 대체하지 않는다. 기존 서비스/제출 프로젝트의 데이터를 끌어오지 않는다.
